## 1. 本轮目标与不做的事

### 目标

生成一组组满足明确定义的训练数据：

**人工多光源输入 + 逐像素相机白点 + 去色偏但保留新明暗的目标图 + 有效性信息。**

并回答两个独立问题：

1. 去掉估计的旧明暗，是否比在旧明暗上叠加新照明更有利于真实 AWB？
2. 新照明与场景表面朝向对应，是否比相同照明图与场景错位更有效？

数值自洽、下游有效、真实物理正确，是三个不同层次。第一项通过不能替代后两项。

### 范围

首轮采用**线性相机 RGB 的对角近似、直接漫反射、两盏方向光**，各灯有一个固定比例的同色弱背景项。

首轮不加入镜面、高光生成、透明、完整 BRDF、真实投影阴影、互反射、三光源、可微渲染优化、扩散修图、新 loss 或新网络。漫反射并不意味着真实世界没有遮挡和互反射；此处是明确省略这些效应，以检验最低复杂度的模型。[R1]

几何和本征模型是离线的数据构造工具，One-Net 仍是在线训练和推理的消费者。预训练模型引入外部先验，必须披露，不与原来没有这些先验的实验宣称监督资源完全相同。

## 2. 先固定几个名称，避免实现时再混淆

| 名称 | 本文件的具体含义 | 不能称为什么 |
|---|---|---|
| 白平衡底图 W | 原单光源 RAW 除以其全局白点，仍带旧明暗 | 真实反射谱、纯 albedo |
| 旧明暗 s0 | 从允许的来源图估计的单通道相对照明强弱 | 测量到的真实光照 |
| 颜色底图 Ahat | W 除以受保护的 s0，尽量减弱旧明暗、保留 RGB 比例 | 物体不依赖观察条件的“客观颜色”、D65 标准照片 |
| 法线 n | 表面每一点的朝向，三个浮点分量 | 深度、RGB 材质颜色、唯一出射反射方向 |
| 新照明 H | 两盏灯对该位置贡献相加后的三通道值，含强度和色度 | 只有灰度的 shading |
| 新强度 T | 本轮 G=1 端点约定下，H 的 G 通道 | 实测 lux 或辐射绝对量 |
| 白点 E | 每像素 H 除以自己的 G 通道，E_G=1 | 物体颜色、alpha、完整反射光谱 |
| 中性目标 J | 输入按 E 校正后，保留该版本的新明暗 | 无阴影 albedo、精确 D65 光谱重渲染 |

这里不把 albedo 简写成“D65 下的颜色”。反射属性、相机 RGB 表示与最终显示外观是不同层次；RGB 对角乘法也是对光谱成像的近似，并非光谱乘积积分的恒等替代。[R2]

D65 暂不参与这批标签构造。当前先按既有相机域 E_G=1 协议预测和评分。需要 D65 显示时，应通过已标定的渲染流程另行处理；不能把相机域的 [1,1,1] 默认当成该相机在 D65 下的原始白点。

## 3. 每张来源图只做一次的离线准备

### 3.1 读取允许的数据并核查线性域

图像仍只取官方 Nikon train 的单光源 `_1.tiff` 与 Light1；灯色仍来自既有 train 全局 Light1/2/3 池。不得读真实混光图、真实混合权重、dense GT 或其派生统计来生成训练样本、筛区域、选灯或调参。

先回溯实际 RAW 到 TIFF 的转换、黑电平、RGB 顺序、数值尺度、饱和值、mask 和归一化轴。双高斯报告仍把 TIFF 黑电平/线性来源列为未闭环的继承假设，不能在这版里自动升级为已验证事实。[P1]

若发现基础预处理错误，先留证并提出匹配参照重建，不把修复偷偷混进新增强后宣称提升。缺关键来源证据则暂停正式训练，可继续纯数学测试。

### 3.2 去原光源色偏

沿用已经核查的单光源白平衡：原 RGB 按通道除以 Light1。得到 W。

这一步只去全局色偏，旧照明留下的暗面与亮面仍在。保持浮点计算，不做逐通道剪裁，不因为显示方便把训练图转成 8-bit 或 sRGB。

### 3.3 估计旧明暗，只使用单通道结果

默认沿用前一版 Goal 中的灰度本征分解候选 `compphoto/Intrinsic` / `paper_weights`，固定实际代码和权重哈希；已经有可核查缓存时优先复用，不重复推断。[R3][R4]

只把估计的灰度明暗迁移回相机域；不把网络预测的彩色 albedo 直接当 RAW 的材质真值。

必须核查字段语义：本次读到的 `intrinsic/pipeline.py`（blob `f46cd77371d15870fe93ad67808b19c4a46671b8`）将 `inv_shd` 写进 `gry_shd`。因此先按固定依赖的 `uninvert` 解码，再用线性 shading 做除法，不能按字段名称猜。

工程操作为：先将 inverse shading 保护在解码定义域，解码成线性 s；记录零值与非有限位置；再插值对齐到来源图。**先解码，再插值。** 用模型内部 `lin_img` 与 `gry_alb` 的关系检查解码单位，但不能用这个恒等关系证明分解真实。

模型辅助输入与训练 RAW 分支严格分开。辅助输入可使用已验证相机矩阵形成的线性显示 RGB；没有标定矩阵时，使用 camera-linear proxy 必须标记域外近似，不伪称标准 sRGB。固定全图缩放，避免重复 gamma。外部模型的彩色输出、自动色调映射和显示剪裁不回写训练底图。

### 3.4 有限度地去旧明暗

在预先确定的有效区域上，用中位数消除估计明暗的整图尺度歧义。初始保护范围沿用前一版 Goal：相对明暗限制到 0.25–4。将 W 的三个通道同时除以该单通道场，得到 Ahat。

这项操作保持同一像素的 RGB 比例，主要改变明暗；它不恢复光谱，也无法找回原图暗部已经没有记录下来的细节。Ahat 不保证数值在 0–1，不要为使其像“反射率”而逐通道截断。

上述范围只是固定的工程起点，不是物理真值或论文最优值。保留未保护的估计、保护后的 s0、限幅比例、暗部放大情况。

### 3.5 估计并保存法线

优先使用来源、坐标和对齐均可核查的历史法线缓存；没有时才固定一个法线估计器。前一版 Goal 的备用候选是 DSINE；实际版本、内参和坐标约定必须先核实再冻结，不一边训练一边更换模型。

法线存三个 float32 分量，单位长度；可视化颜色不是法线数据。明确“由表面指向光源”的灯方向定义，检查正面平面、侧面平面和翻转等基本关系。

本轮不把材质颜色边界直接转成法线或 alpha 边界。同一平面的红纸与白纸可以接受相同照明；法线相同则同一灯的几何贡献相同。这是本轮直接漫反射模型的定义，不是所有真实场景都满足的结论。[R1]

### 3.6 缓存与风险

每张图缓存：来源引用与哈希、W、线性旧明暗、保护后 s0、法线、技术有效 mask、风险记录、辅助输入转换以及预训练模型身份。

技术有效性与“真实漫反射”不是一回事。饱和、极暗、透明、发光、高光和明显彩色互反射在首轮记录为风险；没有可靠全量识别器时，不假称已经准确剔除。不要另加未验证的材质分类网络扩大范围。

训练各臂使用同样的技术有效位置和损失分母；正式测试仍用历史冻结 mask。屏蔽某些 patch 的监督，也不等于整图分支完全没看到这些区域，须披露。

## 4. 每次训练在线生成什么

### 4.1 数据复用方式

所有来源图都可以在不同访问时保留原光或接受人工新光，不永久分成不同场景组。原流程本来就是在线增强，本版不宣称从离线变在线。

接口可以支持原始单光源、人工单光源和人工多光源。为了只比较重光照构造，首轮沿用核查后的 O 状态清单，不新增人工单光源占比、状态轮换或强制共享 crop。O 的约 50% 原图、50% 混光是匹配对照条件，不是最佳比例结论。

每次混光只读离线缓存，在线计算灯方向、点积、乘除和标签，不在训练循环中运行本征/法线大模型。

### 4.2 两盏灯分别随机什么

- 颜色：完全沿用 O 的同相机 train 端点池和抽样规则，各端点按 G=1 表示。
- 方向：两盏方向光独立抽取，围绕已验证的正面方向；方位角均匀，cos(theta) 在 cos(70°) 到 1 之间均匀。
- 相对强弱：r 在 -1 到 1 stops 均匀采样，a1=2^(r/2)、a2=2^(-r/2)，相对功率比为 1/2 到 2。
- 背景项：eta=0.1，每盏灯自带同色弱背景分量；不是另加一盏实测白灯。

这些起始设置沿用前一版 Goal，均为待验证的工程配置。没有完成物理/数值校准前不视为冻结实施参数。校准若需修改，先登记并重新核查，不能根据真实 test 调值。

两灯同时等比例变亮主要改变曝光；只改变其中一灯的功率，会改变混合白点，不会一般地被 z-score 消掉。

### 4.3 怎样从法线得到每盏灯的贡献

表面越朝向灯，贡献越大；背向灯时直接分量为零，只保留上述弱背景。使用 Lambertian 入射余弦项，而不是把法线解释成唯一的反射射线。[R1]

采用方向光是为了先避开不可靠的绝对距离和点灯位置。本轮没有可见性求解，因此没有正确的新投影阴影，也没有红墙反射光等互反射；不得声称完整物理渲染。

### 4.4 怎样合成照片和白点

两盏灯在每个位置的“贡献强度 × 灯色”相加，形成 H。H 的颜色分量给出局部白点，强度分量给出新明暗。

主要候选输入：**去旧明暗底图 Ahat × 新照明 H**。

逐像素白点：**H 的 RGB 各通道除以同一位置的 H_G**，得到 E，绿通道为 1。

中性目标：**Ahat × H_G**，保留新明暗但去除新灯色。

alpha 由两灯贡献的比例派生，作为记录和诊断；本轮不独立随机画 alpha，不用原照片的像素亮度冒充两灯各自的照明贡献。

## 5. 输入、标签与材质保留的关系

第一版真正保留的是来源 RAW 的空间纹理和每像素 RGB 比例；法线决定新灯对各处的几何作用；估计 s0 用于减弱旧明暗。三者分工明确。

用于训练的 E 是**在这套简化生成模型内已知的标签**。它不意味着真实相机在任意光谱、材质下重新拍摄一定得到相同 RGB，更不是“通过自洽检查就被授予真实 GT”。用户提供的调研材料提出了生成后质检的思路，本版仅将其用于排错，不采用其把质检等同于物理真值的强结论。

先逐像素得到 G=1 的 E，再按历史有效 mask 对 16×16 patch 取平均并按旧 loss 接口归一化。不能先平均带亮度的 H 再归一化，否则会引入额外亮度加权。

若未来明确要求 D65 目标，需要独立定义该相机的参考白点及光谱/显示流程。当前局部白点评估不暗中换成 D65 重渲染评价。

## 6. 统一 A/B/C：先找已做记录，再决定是否需要补跑

为避免与旧的 crop C、双高斯 DG-C 混淆，以下使用完整名称，括号内才保留 A/B/C。

| 配置 | 输入构造 | 唯一直接比较 |
|---|---|---|
| DR-A：保留旧明暗 | W 乘 H | 与 DR-B 比是否减弱旧明暗 |
| DR-B：替换旧明暗 | Ahat 乘相同 H | 主要候选 |
| DR-C：照明错位 | Ahat 乘旋转 180° 后的 H | 与 DR-B 比空间对应 |

DR-C 不旋转底图和旧明暗；三个 RGB 照明通道一起旋转，并从旋转后的 H 重新计算 E 和中性目标。它是新照明与场景错位，不是输入与标签错位。

三臂的初始权重、来源、状态、crop、patch、端点、灯方向和相对功率由同一清单控制。A/B 的 H 与 E 相同；B/C 的 Ahat 相同。各视图内的整图和 patch 必须来自同一次重光照。

几何增强约定：先把 W、s0、法线共同重采样到最终训练网格，再计算 H、输入和标签。法线与灯方向使用同一已声明坐标基；若把增强当图像样本重排，则不额外猜测翻转分量，若改变坐标基则两者同时转换。必须有等价性测试，不能各模块自行定义。

C 在完整网格保留 H 的值集合，但不保证在非对称有效 mask、局部 patch 或整图上下文中所有统计都相同。平面、对称场景的干预可能很弱。报告实际差异，不按模型误差挑更强的错位案例。

O 只作现有性能参照；因为三臂都增加了外部先验、几何和可能的新技术 mask，不能把 DR-B 对 O 的全部差距归因于去明暗。解释去旧明暗看 B-A，解释空间关联看 B-C。

如本地存在等价且已完成的 A/B/C，本节只用于对账和解释，不授权重跑。需要重建参照或添加第四个正式训练时，先单列原因与预算，不静默扩组。

## 7. Goal 模式执行顺序与交付物

### 阶段 0：结果与来源盘点

交付 `00_existing_runs.md`、`source_manifest.json`、环境/代码/权重身份、数据访问策略。

先解决照明错位 C 的结果归档。再核查线性域、黑电平、RGB 和原标签定义。缺输入或关键证据，状态为 BLOCKED，不自动改项目边界继续跑。

### 阶段 1：固定 24 张 train 来源的离线预处理

使用事先固定的 scene_id 哈希规则抽 24 张，不能按 AWB 误差或最终效果挑图。生成旧明暗、法线、Ahat 和风险记录。

本次交付为文字方案，不要求再画说明海报。执行时应保留实际生成样本，供查看图片和数值核对；图片只是产物，不是“看着更真实”的性能证据。

交付 `01_cache_qc.md`、每图元数据与缓存。出现系统性颜色纹理被误当旧明暗、严重法线错向或暗部噪声放大时，先停止并解释；不能强行完成全量缓存后训练。

### 阶段 2：独立于 Nikon 测试数据的数值与模型检查

至少完成：

1. inverse-shading 解码正确；零值与非有限位置处理一致。
2. 每臂输入除以自己的 E 等于对应 J；有效区域 float32 相对误差建议小于 1e-5。该数值阈值仅检查实现。
3. 两灯同色时 E 不随法线和材质颜色改变。
4. 相同平面法线的红白纹理边界不人为产生白点边界。
5. 同材质不同朝向受光不同；灯的左右坐标关系正确。
6. 共同改变两灯强度不改变 E，改变相对功率在非退化场景中改变 E。
7. C 的 H 确为同一数组的空间置换；C 的输入与标签自洽。
8. 原图分支不因新增随机流、曝光或缓存而改变；关闭新增开关复现父项路径。
9. 经过实际整图/patch 归一化后，新照明干预仍可见；记录哪些变化被消除，不能只看保存图。

用已知平面、折面或球面法线做解析检查，无需建立完整资产库。重建恒等式不证明 s0 是真实旧照明；已知场景检查也不替代真实泛化。

交付 `02_generator_tests.json`、简要检查报告和可重放参数。以上任何关键项失败，不进入训练。

### 阶段 3：冻结版本与真实输入校准

固定全部状态清单、参数、mask、随机流、初始权重和预算；缓存通过后处理全量允许来源。缓存失败或 mask 导致数据集变化必须披露，不能默默换成容易子集。

完成真实 full-batch、末尾 batch、有限梯度和参数更新检查。校准权重不得用于正式训练。

数值余量按三臂反事实最大值计算同一个整图缩放系数，应用于各自 I 和 J，E 不变；原图分支不动。禁止各臂独立自动曝光，禁止逐像素/逐通道裁剪来掩盖溢出。上限沿用阶段 0 已核实的域约定，不盲套某个 TIFF 数字。

交付 `03_frozen_manifest.json` 与校准结果。若尚无实施授权，停在此处等待，不把用户要求更新文档视为开跑许可。

### 阶段 4：必要时最多三个新的 seed0 正式训练

仅在未做过等价实验、实现闸门通过且获得授权时，分别训练 DR-A、DR-B、DR-C。每组 69,600 次成功更新，沿用旧 One-Net、损失、AdamW、学习率日程、每源两视图、每图 64 patch 及对应 batch 消费。

均从同一协议冻结的随机初始权重出发，不加载 O 训练权重续训。真正消费的有效 patch、状态比例、跳过样本和缓存覆盖必须记录，不能只匹配 optimizer 次数。

不新增 consistency、序数、材质预测或几何辅助 loss。网络看的是合成 RGB，不额外接收真实或预测法线作为输入。

### 阶段 5：先冻结开发选择，再统一真实评分

沿用既有真实单光源 val 与四类固定合成 val、train 端点、原开发分数；保留 O 候选。不能另造一个只像本生成器的开发集代替原验证，也不能在训练中使用真实混光 GT 选择 checkpoint。

先保存候选身份、开发分数及选择时间，再一次性统一评分。报告完整 18 格与 A/B/C 直接差值，不能只摘取最好一格。历史 test 已被查看，仍是披露过的探索性迭代，不称全程盲测。

保留原 seed0 门槛、追加 seed 条件和三 seed 汇总规则。没有通过就报告没有通过，不能自动放宽阈值或反复用 test 扫灯方向、eta、s0 范围。

交付 `04_results.json`、`05_analysis.md`，分别回答实现是否正确、B-A/B-C 是否出现信号、最终目标是否达到。单 seed 信号不是统计稳定结论。

## 8. 完成后如何决策

- B 比 A 好：支持本版本的有限去旧明暗操作有利。不能据此直接证明恢复真实 albedo。
- B 比 C 好：支持本版本的场景—照明空间对应有用；要同时报告 C 的干预强度与局限。
- B 比 O 好但不比 A 好：不能声称去明暗有效；可能来自三组共同变化。
- B 与 C 接近：先查是否大面积为平面、干预很弱或预测法线很差，不能直接否定一切几何信息。
- 三组均不改善：结束本批，不继续无上限调参。结合缓存和独立检查，区分本征估计问题、几何问题与模型表达不足。

不把“每项都更复杂”当作进步。若以后确实增加投影阴影或互反射，分别建立新规格与 GT 定义；不能把它们悄悄加进这三个对照。

## 9. 后续分支，首轮不实施

**投影阴影：**法线点积不包含“灯与表面之间被别的物体挡住”。需要几何可见性，不能靠把 alpha 边缘变尖冒充。

**彩色互反射：**邻近材料可改变局部入射光谱，使白点不再位于两个全局灯色的混合线上。此时“中和局部入射光”和“把所有灯改成白灯后重渲染”不是同一个目标，要先明确标签语义。

**少量额外拍摄：**用另一方向的同色单灯观测检查换光预测，是有价值的独立物理验证，但它是新增数据条件，不能混进原 `_1`-only 构造边界。未取得这种验证时，只能报告模型内自洽与下游效果，不能宣称真实传输已验证。

**光谱仿真：**RGB 底图不能唯一恢复反射谱。需要已知/额外估计的光谱与相机响应，才能研究真实换光的非对角误差；本版不伪造这些信息。

## 10. 给实现者的最少算式（正文步骤的精确定义）

以下用于消除命名歧义，不要求阅读者先学会渲染公式：

```text
W = linear_raw / normalize_G(Light1)
s0 = clip(s_linear / median_valid(s_linear), 0.25, 4.0)
Ahat = W / s0

u1 = a1 * [0.1 + 0.9 * max(0, dot(n, d1))]
u2 = a2 * [0.1 + 0.9 * max(0, dot(n, d2))]
Hraw = u1 * L1 + u2 * L2       # L1_G = L2_G = 1
H = Hraw / median_full_grid(u1 + u2)
E = H / H_G
alpha = u1 / (u1 + u2)

DR-A: I = W * H;                 J = W * H_G;                 GT = E
DR-B: I = Ahat * H;              J = Ahat * H_G;              GT = E
DR-C: HC = rotate_180(H)
      I = Ahat * HC;             J = Ahat * HC_G;             GT = HC / HC_G
```

相对尺度/曝光和 Lambertian 的共同常数可吸收到本轮统一约定；不声称 u 为绝对光度值。所有乘除按正确维度广播。未知、无效或有饱和的位置按冻结规则处理，不临时按误差筛除。
