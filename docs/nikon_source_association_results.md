# Nikon 源图—整对白点关联：AN/PS 完整负结果

Updated: 2026-09-25 · Agent: codex

AN 与 PS 两个 seed 0 训练及冻结后的最终评测均完成，但没有达到原 baseline 的逐格改善目标。冻结开发选择仍为父项 O；O、AN、PS 分别为 0/18、3/18、3/18 格严格优于 baseline。AN/PS 仅改善 val 单光源的三个均值，全部 test 格均未改善。没有启动 seed 1/2，三 seed 目标未完成。独立审计为结果正确性 PASS、性能 FAIL、契约 ADEQUATE、S1 完整可追溯失败实验，不能称为 S2 性能成功。

## 问题与固定边界

研究对象是从单光源来源生成合成多光源监督，减少真实混光逐像素标注依赖。图像来源限 668 张官方 Nikon train 单光源 `_1.tiff` 及各自 Light1；允许全部 1,353 个有效 train 全局白点，包括多光源场景 Light1/2/3 的颜色。全局颜色不等于空间混合标签。真实混光图像、dense GT、混合权重及其派生统计不得用于构造、训练、开发选择或调参；人工生成的光照图可用于合成监督。

白平衡图像 B = RAW / Light1 仍含原始明暗和噪声，不视为物理反射率。合成 RGB 为 B × E，E = alpha × e1 + (1-alpha) × e2；归一化后的 patch 平均 E 提供训练标签。One-Net 固定 42,179 个参数、Eq.5、AdamW、原学习率、官方 splits/masks 和随机初始化。每个新臂均完成 69,600 次更新、417 个 cycle，其中 416 个完整 cycle 各 167 次更新，末尾 128 次更新。模型未从父项或校准权重初始化。

原 baseline 使用真实单光源与混光训练，其单 seed checkpoint 是固定历史参照。监督来源不同是研究问题的一部分；本轮不构成匹配多 seed 的统计优越性证明。

## AN 与 PS 改变了什么

构造父项固定为第三轮开发选中的 O，保持原图/全局/混光分支、裁剪、alpha、几何、patch 抽样和既有随机流，仅改变混光分支的端点指派。AN 对每个来源使用自身 Light1，并从合法同场景 Light2/3 中均匀选一个伙伴：631 个来源有一个伙伴、27 个有两个。其余 10 个来源在 AN/PS 中都保留父项端点，不丢弃、不称作同场景配对。

PS 从 AN 的同一整对白点列表出发，在伙伴角色、实际消耗有效 patch 数及 mixed-view 数共同定义的层内，使用非零循环移位置换整对白点。单例层保持不变。每个 cycle（含末尾）及累计的端点边缘计数、联合配对计数，在有效 patch 与 view 两种消耗单位中均严格相同。

| 累计混光消耗 | 有效 patch 单位 | view 单位 |
|---|---:|---:|
| 全部 | 17,712,121 | 278,403 |
| 可置换来源 | 17,449,591 | 274,275 |
| fallback 来源 | 262,530 | 4,128 |
| 可置换来源中的单例层 | 167,243 | 2,737 |
| 配对白点身份改变 | 17,282,348 | 271,538 |
| 保持原分配（含 fallback） | 429,773 | 6,865 |

以全部消耗为分母，配对身份改变比例为 97.573566%（patch）和 97.534150%（view）；保持原分配比例分别为 2.426434% 和 2.465850%。这些是端点身份统计，不证明每个正式 cycle 的所有身份变化都导致 RGB/标签变化；真实 full/tail 校准的有限样本已另外验证有效张量干预。

AN/PS 识别的是源图与整对白点的关联，不单独识别第一端点身份。与父项的比较还改变了端点抽样分布。计数相同不保证 alpha 加权贡献、batch 损失权重或最终像素标签分布相同；PS 不能称为完全去关联。这次负结果也不能证明关联在其他构造中没有价值。

## 独立审计与限制

新的只读上下文从 CSV/NPZ 重新计算全部 72 个均值、54 个差值和通过格数，最大差异 8.881784197001252e-16°。另以 val/test 各一张单光源和一张多光源原始 RAW/GT 独立重建 mask 和 native-grid 评分，四个模型共 16 次 pixel-mean 核查，最大差异 9.992007221626409e-15°；这不是全数据 native-pixel 重算。

审计确认最终选择、checkpoint、代码、评分和历史复用的哈希绑定。完成队列的 717 文件证据清单被重新核对；最终补充核对整体 753 份文件、39 组对应文件及 47 份既有本地文件，无哈希差异。这些范围有重叠，不能相加作为独立样本数。未重新训练、完整推理或回放每次 optimizer 更新；来源限制依据冻结代码、清单和检查，不是历史系统调用跟踪。同一文件系统和模型家族使隔离有限。

AN/PS 在第三轮真实结果前预声明，启动采用“目标未达成”的二元反馈。历史真实 test 已被查看，整个研究过程不能称为 GT-blind 或全新盲测；本轮评分不能反过来作为新构造或调参的 GT 反馈。本结果不主张有效性、新颖性、物理重光照或统计优越性。
