## 已固定的研究边界

- 新方法的图像来源仅为 668 张官方 Nikon train 单光源 RAW 及其 Light1；先白平衡，再构造重光照图像。
- **全部 1,353 个有效训练集全局白点均可用，包括多光源场景的 Light1/2/3。**禁止使用真实混光图像、pixel-wise GT、混合权重图及其派生信息进行新方法构造、训练、开发选择或调参。人工生成的 pixel-wise 光照 map 可以作为监督。
- 固定 One-Net、随机初始化、69,600 次更新、官方 splits/masks 和评测方式。原始混光训练 baseline 仅为比较对象，不提供新方法初始化或 teacher。
- 各方法使用相同 val 和相同 test；val 与 test 本身场景互斥。seed 控制初始化及增强随机性，不决定官方 split。
- 目标是冻结开发集选中的候选在 18 个均值上均低于原 baseline，之后才追加固定配置 seed 1/2。历史 test 已查看，不能称整个迭代是未见盲测。
