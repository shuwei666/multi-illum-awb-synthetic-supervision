01

当前判断

我们已经建立可追溯的单光源来源在线构造管线，也观察到比早期构造更低的误差，但还没有达到原 One-Net baseline。当前最有价值的下一步，是完成正在运行的七组，判断去旧明暗、新明暗和空间对应中哪些操作值得保留。

来源仍是 668 张 Nikon train 单光源图；允许使用 1,353 个 train 全局白点，包括多光源场景中各盏灯的颜色。真实多光源 RAW、混光图及 dense GT 不进入新方法构造和选模。已有 Intrinsic/DSINE 缓存属于外部学习先验；因此我们的目标是减少目标数据集的真实混光逐像素标注，不能称完全无监督或无外部数据。

实际取得了什么进展

下表为历史 test 平均角误差，单位为度、越低越好。Patch 汇总有效 patch，Pixel 先图内平均再按图等权。Test 共 204 张，其中单光源 97、多光源 107。不同批次只能描述数值趋势，不能据此作唯一变量因果解释。

O 相比早期 M 的全部 Patch 误差下降约 0.302°；这是多个阶段修改后的观察，不能全部归于某一项。O 相比 baseline，单光源仍高 0.174°，多光源高 0.709°，主要差距在后者。旧 C 的数值较低，但其所在批次开发选中的是 O，C 不能据 test 被重新宣布为正式赢家。

已试路线还包括源图与整对白点关联 AN/PS，以及共享 crop 的 Pair-M/Pair-Gaussian。前者没有 test 改善到 baseline；Pair-M 的开发分数 0.824048 好于 O 的 0.857399，但 test Patch 为 2.454641°，差于 O。低频 low 也出现开发优于 full、test 较差的情况。它们提示开发指标对真实表现的预测存在局限，尚不能据此断言开发集错误，更不能用 test 反调开发权重。

目前没有可靠证据表明高斯、先验去明暗或场景对应越复杂，效果就越好。源图数量、端点覆盖、patch 内混光变化和先验误差都是待检验解释，尚未定位为失败原因。

03

当前七组要解决什么

规范固定于上游 2c52cbe，运行实现 b17058e。2026-09-26 20:47 的实际心跳显示 ES00 已完成至少 67,802 / 69,600 次更新，其余六组等待；此处是时间快照，当前进度以运行记录为准。尚无本批 test 结果。

对照 能回答的问题
ES00 / ES10 / ES01 / ES11 光源色度 E 和中性强度 S 的位置，各有什么作用，是否有交互？
ES11 / KEEP_OLD_R 相同新照明下，去旧明暗是否有用？
ES00 / SHAM_OLD_0 旧明暗图与源图逐点对应，是否比错位调制更有用？
NO_NEW_S / ES00 / ES01 新增中性明暗是否必要，位置是否影响效果？

七组共同 mask、曝光、采样与预算，各 69,600 次更新，合计上限 487,200。它们识别的是固定先验和参数下的训练效果，不能证明真实反射率恢复、精确几何或物理重光照。18 格包含重复口径与相关子集，也不是 18 个独立统计检验。

04

后续优先级与停止条件

第一优先级：完成本批并形成机制结论。 当前已授权。完成七组后，按冻结开发分数选候选，统一报告 val/test 的全部、单光源、多光源，以及 Patch/Pixel 和九个预声明机制差值。每个比较都保留反例和限制。技术失败停止留证；性能不好也完成既定七组。本批结束后不自动扩展。

第二优先级：给下一轮确定一条可证伪主线。 以下仅为待决策建议：若配对对照和允许的开发证据共同支持取消新明暗或去明暗模块，优先验证更简单的构造；若只在真实 test 上变好，保留为事后观察，不能据此改生成器或换 winner。若新明暗确有开发收益，再围绕已有色度—明暗交互提出一项明确假设，避免重新扫描高斯宽度、去明暗强度或灯方向。

若七组仍未达标且机制证据不清楚，暂停增加几何模块。 先做无需重训的允许数据审计：光源池与已消费虚拟白点的色度覆盖、crop/patch 对每个源图的覆盖、patch 内白点变化、四类合成开发任务的覆盖。只用 train 白点、允许单光源图和人工标签；真实混光 GT 的误差分析仅作冻结后的描述。在线生成数量不等于独立场景数量。这项审计若不能给出明确缺口，就停止继续堆增强；若找到缺口，再提出最多一对匹配训练及固定预算，另行确认后执行。

第三优先级：达到门槛后验证稳定性，再讨论扩展。 维持现有“开发预选候选的 18 格均严格优于原 baseline”门槛。达到后，下一阶段建议冻结方案补 seed 1/2；这些训练不属于当前七组授权。若要主张统计优越性，还需匹配 baseline 的重复训练；若要主张相机泛化，还需单独设计场景隔离的跨相机验证。历史 Nikon test 已多次查看，不能作为全新盲测。

05

可形成的研究贡献与证据边界

值得争取的贡献是：在只保留单光源来源及训练白点的条件下，找出足以训练局部白点估计的最小构造，并量化目标数据标注成本、外部先验成本与真实误差的取舍。当前已经有受控负结果和执行证据，尚无性能达标、多 seed 稳健性或新颖性证明。本次未作新文献综述，不把实验设计本身称为创新已成立。
