版本：1.0 / 2026-09-26
性质：ChatGPT 的研究设计与执行任务书。不是已完成实验，不是文献已证明的性能结论。
对象：在本地具备数据、训练实现和计算资源的 Codex / Claude Code / GLM Goal 执行器。

0. 本轮总目标与边界
总目标：检验两件事是否让单光源来源的虚拟监督更有效：①减少底图中的旧明暗；②让新照明与场景表面朝向对应。保持 One-Net 消费者不变。
第一版只做 RGB 对角、漫反射近似下的重光照，不识别木头/塑料等材质名称，不恢复光谱反射率、金属度或完整 BRDF，不模拟镜面、透明、真实投影阴影、互反射或不可见几何。
把任务分成三个层级，不得混为“成功”：
1. 实现完成：公式、数据域、坐标和 GT 一致，测试通过，能复现。
2. 机制信号：在匹配对照下，去旧明暗/空间对应出现有利差异。首轮只有 seed0，只能称观察到信号。
3. 最终性能目标：按照仓库原冻结契约，预选候选逐项超过原训练 baseline，并满足原有追加 seed 与汇总规则。没有达到就报告未达到，不无限迭代到成功。
本批默认最多 3 个新的正式训练：A、B、C，各 69,600 次成功 optimizer updates。校准从独立权重进行，不计正式预算；校准权重绝不用于正式训练。若发现必须重做参照或修改底层预处理，停止并单列下一批方案，不私自增加第四个正式训练。

3. 阶段1：离线估计旧明暗与表面朝向
昂贵模型只离线运行一次。训练期间只读缓存和执行乘除、点积。
3.1 先处理固定24张train检查图
按scene_id的SHA256排序取前24张（固定盐 diffuse-vgt-v1），不得按AWB误差或效果选图。可额外补充少量结构例图用于人工检查，但不拿这些补图调测试集性能。
每张图输出：W预览、旧shading、法线、去明暗底图、有效性/风险图、新灯作用、A/B/C输入及其GT。先看这些图和数值，再批量缓存全部来源。
3.2 旧明暗：只用灰度分解，不采用网络彩色albedo
默认依赖 compphoto/Intrinsic，使用 paper_weights 的灰度阶段。固定代码commit、依赖及权重SHA256。灰度模型有官方实现，单图分解本身是欠约束估计，不是测得真值。[R3][R4][R7]
特别重要：本次核对的实现并非把线性shading直接放在 gry_shd 中。
intrinsic/pipeline.py先计算 shd = uninvert(inv_shd)，随后却把 inv_shd 写到 results['gry_shd']。因此不能直接 W / results['gry_shd']。应使用固定版本的 chrislib.general.uninvert 解码。对应依赖9a4c63f中：
D = clip(inverse_shading, 0.001, 1.0)
s_linear = 1 / D - 1
D=1会得到0，需标记无效；零值不能无条件当作正常shading。[R3][R4]
建议接入接口（需在本地固定版本核对）：
models = load_models('paper_weights', device=device)
out = run_gray_pipeline(models, proxy_linear,
                        linear=True, resize_conf=1024,
                        maintain_size=False, device=device)
s_raw = uninvert(out['gry_shd'])
gry_alb只能用于校验该模型内部输出关系，不作为相机RAW彩色底图。ord_full/ord_base是ordinal表示，也不能作为物理shading。
输入域
- 相机RAW分支：始终在原线性相机域计算W、I和GT。
- 模型辅助分支：有已验证固定相机→显示RGB矩阵时使用它构造proxy；没有时使用全局缩放后的camera-linear proxy，并在报告明确域外近似，禁止伪称标准sRGB。
- 采用单一全图倍率使辅助线性proxy处于[0,1]。对辅助proxy产生的剪裁单独记录，绝不把它传回训练底图。
- linear=True时不再做gamma幂；DSINE需要的显示proxy由同一proxy单独编码。禁止把相机RAW直接又乘2.2次幂或重复白平衡。
- 仅将对齐后的标量明暗图迁移回RAW；不从外部网络引入新的三通道物体颜色。
尺度与除法保护
在原有效区域上令 s_rel = s_raw / median(s_raw)。使用 s0 = clip(s_rel, 0.25, 4.0) 作为首轮固定的有限度去明暗场，记录上下限命中率。
Ahat = W / s0只是相对颜色底图，不保证物理albedo处于[0,1]，不做三通道裁剪。除法的最大增益为4；不尝试恢复原图根本没有记录的暗部细节。中位数归一是消除尺度歧义的约定，不是曝光测量。
在模型内部的原输出网格上，用未保护的s_raw检查 lin_img ≈ gry_alb * s_raw，只验证字段/单位解码。此恒等关系不证明材质与shading分解正确。随后将线性s_raw对齐到来源网格，先解码，再插值。
3.3 法线：优先复用可信缓存，否则只选一个固定模型
若本地历史法线缓存可核验来自相同允许来源、与像素对齐且坐标明确，优先复用，不同时更换几何估计器。否则默认DSINE exp001_cvpr2024官方权重，固定commit和hash。[R5]
DSINE以相机内参或近似内参为输入；优先使用原图内参并随尺寸正确缩放。没有时沿官方示例的近似方式，写明使用近似内参，不能说恢复了准确几何。
法线必须存float32三分量数组，而不是量化到8-bit的彩色可视化图。每个有效向量重新归一化。
**坐标适配是强制测试：**记录模型轴向/正负号，统一“表面指向光源”的方向约定。不得凭显示蓝不蓝猜坐标，也不得随意全局翻负号。检查朝向相机的平面在正面灯下比侧灯亮，左右翻转试验可解释。仓库文档的坐标说明必须与实际版本共同核对。[R5]
3.4 有效性与“材质”范围
本批不使用材质分类模型。保留真实颜色纹理，用漫反射假设建模；在已知或人工检查标注中，饱和、极暗、高光、透明、发光区域作为风险，不称作精确漫反射GT。
主训练沿用原mask，并加相同的几何/分解技术有效性mask，A/B/C完全一致；不因某一臂产生大loss临时删样本。没有可靠全量非漫反射mask时，明确这是“漫反射近似应用于一般场景”，不是“已验证纯漫反射数据集”。训练mask不改变正式测试mask。
整图上下文分支仍可能看到风险区域；仅屏蔽局部监督不等于彻底消除了它们的影响。报告这个边界。

4. 阶段2：构造双方向光（不再单独画随机alpha）
本轮固定两盏方向光，避免引入不可靠绝对深度、距离衰减和点光源位置。法线、底图与shading先按同一几何变换映射到256×256训练网格，再在这个网格上计算最终图和GT，避免把RGB乘积和GT分别resize导致代数关系不一致。
几何增强在本轮定义为对原相机坐标下表面样本的共同重采样；法线向量和灯方向保持同一坐标基，不额外凭经验翻转分量。若代码采用旋转后的相机坐标，法线和灯方向必须同时变换，并用等价性测试验证。二者只能选择一种实现并冻结。
4.1 灯的抽样（本方案初始工程值，不是文献最优参数）
- 色度：完全复用O允许的端点抽样，不增加角色关联或夹角筛选；端点归一到G=1。
- 方向：各自独立采样，绕已验证的正面方向，方位角均匀[0,2π)，cos(theta)均匀[cos(70°),1]。
- 相对功率：r ~ U(-1,1) stops；a1=2**(r/2)、a2=2**(-r/2)，功率比覆盖1/2到2。全图共同强度无须另设自由度。
- 背景系数：eta=0.1。把每盏灯建模成方向分量加一个同色弱背景分量，确保正值。这不是测得的真实环境光。
4.2 成像公式
u_k(x) = a_k * [eta + (1-eta) * max(0, dot(n(x), d_k))]
H_raw(x) = u_1(x) * L1 + u_2(x) * L2
T_raw(x) = u_1(x) + u_2(x)        # 因L1_G=L2_G=1
m = median(T_raw)                 # 整个训练网格上的一个标量
H = H_raw / m
T = H_G
E = H / H_G
alpha = u_1 / (u_1 + u_2)        # 仅作诊断，不是另一个独立随机场
两个灯的相对功率改变E，不会等价于统一曝光倍率被消掉。 主次光权重不由物体亮度直接决定。
4.3 A/B/C精确定义
A: I_A = W * H
   E_A = H / H_G
   J_A = W * H_G

B: I_B = (W / s0) * H
   E_B = E_A
   J_B = (W / s0) * H_G

C: H_C = rot180(H)                # RGB三个分量一起旋转；底图和s0不旋转
   I_C = (W / s0) * H_C
   E_C = H_C / H_C_G
   J_C = (W / s0) * H_C_G
J是去色偏、保留该版本明暗的目标。A/B的E完全相同；C的E按新场重算。每臂的正确关系是 I/E = J，不是统一回到W。
如果需要数值余量，沿DG已经审查过的方式，对同一来源/光照种子的A/B/C共用一个整图二次幂缩放系数，依据三臂反事实最大值计算。I和J一起缩放，E不变。不得按臂独立自动曝光，也不得逐通道/逐像素clip。最终继承什么上限由阶段0记录，不能把60000之类的历史值不加核查套进归一化输入。
4.4 Patch标签
先在每像素把H归一为G=1的E，再按原有效mask对16×16区域的E取均值，最后按原loss接口所需方式归一。不得先平均带明暗的H，再归一；那会隐含亮度加权，改变GT定义。
每臂mask、有效patch槽位与loss分母必须一致。C在全网格保持H的值分布，但在非对称有效mask上的分布不一定相同；保存相应统计，不能声称一切边缘分布严格匹配。

- 单臂失败则保存错误、状态及已完成更新数；最多两次有记录的集成修复。修复导致核心公式/数据变化时创建新版本，不能把部分旧训练算进新配置。
- 记录预处理离线耗时、每步在线耗时、峰值显存、缓存大小；不把历史12分钟承诺给这次包含外部模型的全流程。
7. 阶段5：开发选型与最终评分
固定开发
保留旧五项代理验证和旧分数（真实single一项＋四类synthetic）。同时报每一子项，不能只报总分。A/B/C各使用其final checkpoint。
将O与A/B/C一并纳入候选，按原冻结分数最小者预选；精确同分优先O，再A、B、C。这是一项为本批预先固定的平手规则，不是基于最终test改选。若仓库已规定不同候选顺序，先在冻结表中采用原规则。
最终评分
登记预选、checkpoint hash及时间后，一次性统一评分O、A/B/C及原baseline，报告全部val/test × all/single/multi × patch pooled/patch image-balanced/pixel image-balanced。沿用原测试mask/图像身份，不只评本方法认为漫反射的测试区域。
可新增诊断列但不能替换原指标：每图误差差值、场景级聚合、多光源尾部、B-A、B-C；同场景多个composition不是独立样本。只有已保存且可核验的逐图/逐场景数据才能计算置信区间；单seed的场景bootstrap不等于训练seed不确定性。
两类判定
- 最终性能：完全按原18格契约判断。未通过则 FINAL_TARGET_NOT_MET；不能将下降某一格称为总体成功。追加seed按原授权条件，不因本计划自动放宽。
- 机制观察：报告B-A、B-C在开发子项和最终各子集的方向、幅度、局限。不能仅凭B比O低就证明去阴影有效；不能把单seed小差异叫统计显著。C干预强度低时结论标为不充分。
本轮看过真实评分后结束。不根据这些test细节自动调灯角度、eta、s范围或选择新mask。

9. 本轮之外的真实换光验证（不自动要求采集、不自动扩展预算）
若用户另外提供相同场景、同一灯色、不同照射方向的独立RAW，可建立单独的物理验证集。第一张用于估计，其他照明下的图只作预测检查，不反向当成本轮训练底图或修改alpha的来源。
需要真实方向/近似照明设置、曝光关系、配准与非饱和有效区域；没有这些不能假装“预测第二张照片”。每图允许一个曝光尺度匹配，禁止逐像素对齐亮度后再评价。
此验证未完成时，最强结论只能是“外部先验辅助的合成监督在下游产生/未产生某些收益”，不能说真实光照被精确恢复。
