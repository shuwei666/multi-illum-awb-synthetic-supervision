# 单光源来源的合成多光源监督

Updated: 2026-09-25 · Agent: codex

当前主线是 **LSMI Nikon + 固定 One-Net**：仅以单光源图像及其全局光源颜色为来源，通过白平衡与重光照生成训练图像和光照标签，减少对真实多光源逐像素标注的依赖。训练集中的全局 Light1/2/3 色度可作为重光照端点；真实混光图像和真实逐像素混光 GT 不进入新方法的数据构造。

第一轮四个新模型已完成训练和统一评测，**尚未达到原 One-Net baseline 的性能**。第二轮 crop、单光源保留、光源扰动和空间明暗增强正在运行：启动复核通过，参照M的开发验证已完成，C组训练已启动；本仓库尚不报告第二轮完成结果。

## 当前结果

Nikon 官方 test，204 张 composition 图、52,224 个有效 patch；seed 0，平均角误差单位为度，越低越好。

|---|---|---:|---:|---:|
| 原 One-Net baseline | 既有真实单光源与混光训练 checkpoint，同机复算 | **1.96924** | 1.34651 | **2.53378** |
| G | 空间均匀重光照 | 2.98131 | 1.92581 | 3.93816 |

M 是四个合成训练模型中的最好结果，仍比 baseline 高 0.75655°。四组各完成 69,600 次更新，耗时约 11.5–12.0 分钟，含来源载入、合成和训练，不含最终评测。历史 baseline 本轮复用 checkpoint，未重训。不同监督来源是研究比较的核心差异；此表不是严格唯一变量因果消融，也不证明统计优越性。

## 数据和标签怎样生成

1. 读取 Nikon **train 单光源 `_1.tiff` + Light1**，逐通道计算 `WB = RAW / Light1`。WB 仍含原场景明暗，只是白平衡后的图像，不声称恢复物理反射率。
2. 从 train 全局光源池取端点，生成空间权重 `alpha(x)` 和 RGB 光照图 `E(x) = alpha(x) * L1 + (1-alpha(x)) * L2`。
3. 在线生成重光照图像 `I_syn(x) = WB(x) * E(x)`；**确实有逐像素 RGB 光照 map**，它是人工生成的监督，而不是真实混光 GT。
4. One-Net 为 patch 预测模型：每个 16×16 patch 的训练标签是该区域 `E(x)` 的均值，整图与 patch 分支来自同一次重光照。

**是否生成单光源 relit？** 第一轮 G 已生成空间均匀的全局 relit：整图使用一个固定光源色。该颜色由两个端点的常数凸组合得到，不一定等于池中某个原始端点。第一轮 R/M/P 未设置“原始单光源图”和“单端点全局 relit”的独立分支；第二轮 A/AC 正在增加这两类样本。

所有模型使用同一官方 val 集和同一官方 test 集，val 与 test 场景互斥。split 决定评测图像身份；seed 控制模型初始化、采样和增强随机性。真实多光源稠密 GT 仅用于冻结后的最终评分。
