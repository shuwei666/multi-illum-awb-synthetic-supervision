# 单光源来源的合成多光源监督

Updated: 2026-09-25 · Agent: codex

当前主线是 **LSMI Nikon + 固定 One-Net**：仅以 train 单光源图像及其 Light1 做白平衡，通过重光照生成训练图像和光照标签，研究减少真实多光源逐像素标注依赖的可能性。允许所有 train 全局白点，包括多光源场景各个 Light1/2/3 的颜色；真实混光图像、逐像素 GT、混合权重及其派生信息禁止用于新方法的构造、训练、开发选型或调参。人工生成的光照 map 可作合成监督。

前三轮及 AN/PS 源图—整对白点关联对照的训练与最终评测均已完成，**尚未达到原 One-Net baseline 的性能**。AN/PS 按冻结开发分数仍选中父项 O；相对同一个原 baseline，O 为 **0/18**，AN 与 PS 各为 **3/18**，仅改善 val 单光源的三个指标，没有任何 test 指标改善。未启动 seed 1/2，三 seed 目标未完成。结果可追溯性 PASS、性能 FAIL、契约 ADEQUATE；证据为 S1 完整失败实验，不是 S2 性能成功。

## 数据和标签怎样生成

1. 读取 Nikon **train 单光源 `_1.tiff` + Light1**，逐通道计算 `WB = RAW / Light1`。WB 仍含原场景明暗，只是白平衡后的图像，不声称恢复物理反射率。
2. 从 train 全局光源池取端点，生成空间权重 `alpha(x)` 和 RGB 光照图 `E(x) = alpha(x) * L1 + (1-alpha(x)) * L2`。
3. 在线生成重光照图像 `I_syn(x) = WB(x) * E(x)`；**确实有逐像素 RGB 光照 map**，它是人工生成的监督，而不是真实混光 GT。
4. One-Net 为 patch 预测模型：每个 16×16 patch 的训练标签是该区域 `E(x)` 的均值，整图与 patch 分支来自同一次重光照。

**是否生成单光源 relit？** 第一轮 G 已生成空间均匀的全局 relit：整图使用一个固定光源色。该颜色由两个端点的常数凸组合得到，不一定等于池中某个原始端点。第一轮 R/M/P 未设置“原始单光源图”和“单端点全局 relit”的独立分支；第二轮 A/AC 已加入这两类样本。

所有模型使用同一官方 val 集和同一官方 test 集，val 与 test 场景互斥。split 决定评测图像身份；seed 控制模型初始化、采样和增强随机性。真实多光源稠密 GT 仅用于冻结后的最终评分。
